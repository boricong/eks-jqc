# 개발 인수인계 진입점

최종 갱신: 2026-10-23 · Asia/Seoul

전체 구현 범위, 사용자 결정, 실행 환경, 변경 이력과 기록 형식은 [루트 인수인계](../handover.md)를 따른다. 과거 이력은 원본에 보존하고, 이 문서는 현재 작업의 요약과 진입점을 제공한다.

## 현재 작업 — 홈·인증Set 편집 개선 커밋·푸시

- 2026-10-23 사용자 요청으로 아래 두 UI 개선과 시험·문서 26개 파일의 커밋·푸시를 진행한다. 앞선 구현 단계의 커밋·푸시 제외 범위는 이번 요청으로 변경됐다.
- 원격과 로컬 브랜치 `main`이 일치함을 확인했다. 제품 코드 추가 변경 없이 직전 빌드·Playwright91/91 통과 결과를 유지하며, 실제 커밋·푸시 결과는 확인 후 기록한다.

## 직전 완료 — 인증Set 작성·편집 화면 개선

- 2026-10-23 완료: 큰 구역은 상단 가로 탭, 내부 항목/문항은 공통 세로 번호 탐색으로 통일했다. 학습자료 유형/정보/작업 목록, 입력 폼과 도구 행의 정렬·글자 위계를 정비했다.
- 신규·기존 인증Set 모두 저장과 최신 조회 성공 후 관리 목록으로 이동한다. 저장 결과·보완 항목·연결 자격 안내와 목록 제목 초점, 검색/필터/정렬을 유지한다. 실패/충돌/조회 실패 시 입력을 보존하고 재시도에서 버전을 중복 생성하지 않는다.
- 검증: Node24.22.0 TypeScript/Vite 빌드·최종 전체 Playwright **91/91** 통과. 관련13/13 및 새 화면/저장 시험4/4도 통과했다. 1920/1440/768/390px의 실제 글자·정렬·탭/키보드·긴 자료·빈 항목·500문항·저장 영역의 입력 가림과 대표 변경 전후 캡처를 확인했다.
- 임시 JSON만 사용했다. 앞선 미커밋 홈/프로세스 검토 변경은 보존했고 서버 API·JSON·실행 데이터·의존성은 수정하지 않았다. 서버 단위 시험·커밋·푸시는 수행하지 않았다. 기존 Zod 주석·약552kB 주 번들 경고는 남아 있다.

## 직전 완료 — 홈 히어로 및 MVP 프로세스 검토 개선

- 2026-10-23 완료: 홈의 이름·조직·KST 날짜·현황 3개를 밝은 다색 SVG 히어로로 묶었다. 진행 자격·업무·공지는 아래에 유지한다. 기존 그라데이션 제외 원칙의 홈 한정 예외다.
- 공통 프로세스 검토의 단계 표시·업무/검수 배치·타이포그래피를 개선했다. 기본 접힘·문맥 변경 시 접힘·업무 설명·검토 기준 v11/2026-10-22는 유지한다.
- 검증: Node24.22.0 TypeScript/Vite 빌드, 관련 시험 **14/14**, 최종 전체 Playwright **87/87** 통과. 4역할·1920/1440/768/390px, 실제 그라데이션 픽셀 대비, KST 날짜, 긴 이름/조직, 0건/Hold, 키보드 및 자동 접힘을 확인하고 대표 변경 전후 캡처를 검토했다.
- 시험은 임시 JSON만 사용했다. API·JSON·업무 계산·실행 데이터·의존성은 수정하지 않았다. 서버 단위 시험은 재실행하지 않았고 커밋·푸시도 수행하지 않았다. 상세 규칙은 [UX 설계안](EKS_프런트엔드_UX_설계안.md), 이력은 [루트 인수인계](../handover.md)를 따른다.

## 직전 완료 — 밝은 작업면 중심 프런트엔드 전면 개편

- 사용자 승인: 메뉴와 업무 흐름을 유지하며 Pretendard, 공통 디자인 토큰, 홈·관리 화면의 간소화, 앱 확인창 통일, 반응형·접근성을 정비한다.
- 기준: [AGENTS.md](../AGENTS.md), [DESIGN.md](../DESIGN.md). 기존 API·저장 스키마·업무 데이터는 변경하지 않는다.
- 최신 승인: Stripi 디자인의 인디고·네이비 색상, Pretendard, 제목24/구역18/UI·표14/읽기15px. 둥근 카드 대신 표·목록·구분선과 평면 탐색을 사용한다. 홍보용 큰 제목·그라디언트는 제외한다.
- 완료: 공통 토큰·작은 타이포그래피·상단/관리 탐색, 홈·계획·학습/평가·결과·관리/시스템 화면을 개편했다. 공통 제목·행동 영역·속성 목록·행 더보기를 추가하고 기존 확인창·저장 피드백·오류 연결을 보존했다.
- 검증: Node 24.22.0 TypeScript/Vite 빌드, 전체 Playwright **84/84** 통과. 마지막 모바일 조직 탐색 정리 후 관련 **2/2**와 빌드를 재확인했다. 이전 표 행 높이·붙여넣기 실패도 해결했다. 4역할·1920/1440/768/390px·키보드·대비·긴 내용·10,000행·자동 저장/충돌/복구를 확인하고 대표 화면의 변경 전후 캡처를 검토했다.
- 시험은 임시 JSON으로 진행했다. 실행 저장소와 사용자 변경인 루트 디자인 문서 이동·AGENTS 수정을 보존했다. 서버 단위 시험은 서버 변경이 없어 재실행하지 않았다.
- UX 적용 규칙은 [프런트엔드 UX 설계안](EKS_프런트엔드_UX_설계안.md)에 기록했다. 입력 경계는 선택 배경 대비 3:1을 확보하도록 `#78889E`로 보정했다. 기존 Zod 주석·549kB 주 번들 경고는 남아 있다.
- 2026-10-23 사용자 요청으로 UI 개편과 관련 문서 74개 파일을 `5f4f5bf`에 커밋하고 `origin/main` 푸시 성공을 확인했다. 이 결과를 후속 문서 커밋에 기록한다. 실제 직무 기준의 타당성은 별도 파일럿에서 검증한다.
