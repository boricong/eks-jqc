# 팀 사용자 관리의 소속 조직 선택

업무 수행 상태 컬럼·필터와 개인별 상태 변경을 제공한다. 팀 관리자/운영자만 현재 팀 유효 Auditee 인증 보유자를 Deactive로 전환하며, 6개월 초과 말소와 복귀 후 재취득 정책은 [업무 상태 운영](WORK_STATUS.md)을 따른다. 사용자 이름·소속·역할 편집은 업무 상태와 현재 미수행 구간을 유지한다.

상태는 `active`/`deactive`로 간단히 표시한다. 상태 변경창에는 이름·상태 전환·변경/취소만 표시하며 사유를 입력하지 않는다. 변경 제한 사유는 버튼에 마우스를 올려 툴팁으로 확인한다.

2026-10-28부터 인증 업무 관리 → 팀 사용자 관리의 사용자 추가·수정 입력창은 단계별 선택 목록 대신 **소속 조직 선택 트리**를 사용한다.

## 관리 범위

- 팀 관리자는 관리 대상 Lv1과 모든 하위 조직, 시스템 운영자는 선택한 Lv1과 하위 조직을 선택한다. 세부조직관리자의 사용자 관리 권한은 추가하지 않는다.
- 시스템 운영 → 사용자 관리의 기존 조직 선택 목록과 팀 사용자 목록의 소속 조직 필터는 유지한다.
- 사용자 정보 조회·추가·수정은 기존 `/api/team-users`와 `/api/team-users/:id`를 사용한다. API 요청/응답·저장 스키마·권한과 데이터 이관은 변경하지 않는다.

## 트리 사용

- 수정창을 열면 현재 소속을 강조하고 상위 경로를 펼쳐 선택 행이 보이도록 트리 내부를 스크롤한다. 이름 입력란의 초점은 옮기지 않는다.
- 조직 이름 또는 전체 경로로 검색하고 펼치기/접기로 탐색한다. 같은 조직명은 하단의 선택한 소속 전체 경로로 구분한다.
- 클릭·Enter·Space로 소속을 선택한다. 방향키·Home·End는 초점을 이동하며 내부 스크롤을 따라간다. 검색 입력의 Enter와 트리 버튼은 사용자 저장을 실행하지 않는다.
- 트리 목록의 최대 높이는 데스크톱320px·모바일(640px 이하)240px와 화면 높이35% 중 작은 값이다. 넘치는 목록은 내부 세로 스크롤하며 긴 이름과 경로는 줄바꿈한다. 모바일도 별도 열기 없이 트리를 바로 보여준다.
- 사용 중지 조직은 표시하되 새 변경 대상으로 선택할 수 없다. 기존 소속이 사용 중지인 사용자는 기존 소속으로 되돌리거나 유지하면서 다른 정보만 수정할 수 있다.

## 저장과 충돌

- 트리 선택만으로 저장하지 않는다. **사용자 저장**에서 기존 사용자 revision과 조직 revision을 함께 검사한다.
- 검토 중 조직이 바뀌면 기존 비교/기준 갱신 흐름을 사용한다. 선택 조직이 목록에서 사라지거나 비활성화되면 이름·역할·선택 ID를 보존하고 재선택을 안내한다. 유효한 조직을 선택할 때까지 저장을 막고 다른 조직으로 자동 변경하지 않는다.
- 기존 다른 팀 접근 차단·시스템 운영자 수정 제한·역할 유지·소속 이동에 따른 세부 관리자 지정 해제와 업무 당시 조직 근거 보존을 유지한다. 취소·미저장 이동·저장 실패·응답 유실 재시도는 기존 보호를 따른다.

공유 조직 트리의 임베디드 표시·접근성 이름·선택 가능 ID는 선택 옵션이며 기존 조직 정보/필요자격 화면의 트리 동작을 바꾸지 않는다.
