# Lv1 팀 단위 Auditor 운영

2026-11-02. 업무32·조직5·쓰기 계약5. 계획 workflow v7과 발급 근거 구조는 유지한다.

## 관리 화면 구성

Auditor 관리는 상단 운영 요약, 다섯 업무 메뉴, 팀 학습 안내문 편집 순서로 표시한다. 운영 요약에서 대상 팀의 사용 여부·소속 인원·인증 기준 준비 상태를 확인한다. 메뉴 카드는 자격 풀·인증Set·인증 현황·평가·수료 결과·보유 인증으로 구분하며 설명과 이동 아이콘을 함께 제공한다. 넓은 화면은3열, 태블릿은2열, 모바일은1열로 표시한다.

상단 ‘학습 안내문’은 하단 편집 영역으로 이동해 제목에 초점을 둔다. 안내 제목·본문·자료 링크를 편집하고 저장하며, 저장 오류와 충돌 안내는 편집 영역에 표시한다. 메뉴 이동을 취소하면 미저장 입력을 유지한다. 운영자의 대상 팀 설정은 운영 요약의 별도 링크에서 접근한다.

조직 관리에서는 기본정보·조직 동작 아래에 Auditor 대상 팀 설정을 별도 구분선과 상태 배지로 표시한다. ‘변경’을 눌러 사용·미사용을 선택하고, 모달의 ‘변경’으로 소속 인원·진행 회차·보유 인증과 변경 전후를 확인한 뒤 ‘변경 확정’으로 저장한다. ‘다시 선택’과 취소를 제공하며 확인만으로 설정을 저장하지 않는다. 조직 기본정보에 미저장 변경이 있으면 대상 팀 변경을 보류한다. 모달은 제목과 하단 버튼을 유지하고 긴 본문만 스크롤하며, 요청 처리 중에는 닫기·취소·중복 실행을 막는다.

## 대상과 권한

시스템 운영 → 조직 관리에서 Lv1의 **Auditor 대상 팀**을 설정한다. 하위 조직에는 별도로 설정하지 않는다. 사용 팀의 모든 구성원이 계정 역할과 무관하게 취득 대상이다. 개인별 Auditor 역할 부여는 종료했으며, 과거 역할·지정 근거는 읽기 호환으로 보존한다. 팀 지정으로 타인 관리 권한이나 인증이 부여되지는 않는다.

본인의 취득 가능 여부는 실제 소속 Lv1을 따르고, 관리 메뉴는 현재 관리 팀을 따른다. 일반 업무 메뉴는 자격·학습·평가·인증으로 표시한다. Auditor 관리에서는 현황·자격 풀·인증Set·결과·보유 인증·팀 안내문으로 이동한다. 일반 메뉴를 누르면 일반 업무로 돌아간다.

대상 팀 미사용 시 신규 등록·학습·갱신·재취득은 차단한다. 이미 시작한 회차는 완료할 수 있으며 기존 인증 효력·기간·발급 스냅샷을 유지한다. 관련 개인과 관리자는 기존 기록에 접근할 수 있다. 필수 교육 본인 확인, 일반/메인 선행 조건, 조직 사용 중지 제한은 계속 적용한다. 업무 상태 deactive는 Auditor 절차를 중단하지 않는다.

## 설정 검토 계약

- `POST /api/system/organizations/:id/auditor-eligibility/preview`: 입력은 `{enabled, revision}`이다. 변경 전후·팀 인원·진행 회차·보유 인증 건수와 확인 토큰을 반환한다.
- `PUT /api/system/organizations/:id/auditor-eligibility`: `{token}`과 `Idempotency-Key`로 실행한다. 운영자 권한, Lv1 대상, 업무/조직 revision, 저장소 세대, 15분 만료를 재검사한다. 충돌은409, 권한 부족은403이다.
- 업무·조직은 하나의 파일 쌍 트랜잭션으로 저장한다. 실패 시 복원하며 동일 요청 키에는 최초 결과만 반환한다. 팀 지정 및 구성원 추가 시 지정 알림을 생성하지 않는다.
- 신규 회차 시작은 미사용 시 `409 AUDITOR_DISABLED`를 반환한다. 배정에는 팀 ID·조직 revision·확정 시각을 고정한다. 과거 `designationId`는 당시 근거로만 사용한다.
- 과거 취득 대상자 조회/변경 API는 권한 확인 후410으로 종료된다. 사용자 Hold는 운영 조건에 사용하지 않는다.

## 현황과 안내문

Auditor 모수는 Lv1 및 모든 하위 조직의 구성원이며 비활성 조직은 제외 사유와 함께 표시한다. deactive는 제외하지 않는다. 일반 자격 지표와 합산하지 않는다. 팀 안내문은 홈에서 조회하며, 안내문 미작성이나 기준 준비 부족이 팀 설정 자체를 막지 않는다. 실제 학습 시작에는 자격·필수 교육의 준비 검사를 적용한다.

## 보존 이관과 복구

`npm run data:migrate-auditor-teams -- --dry-run`으로 업무30/조직4 쌍을 검토한다. 기존 개인 지정, 팀 Auditor 자격·진행·인증 근거가 있는 Lv1만 사용으로 전환한다. 중앙 기본자격·공통 원본만 있는 팀은 지정하지 않는다. 기존 계정·버전·진행·답안·수료·인증 내용은 변경하지 않는다. 이관 후에는 명시한 팀 설정을 과거 역할로 재활성화하지 않는다.

서버 중지 → 최신 소스와 업무·조직·관리 파일 백업 → dry-run → revision·두 파일 SHA256 조건부 적용 → 재시작 → 보존 대조와 읽기 검증 순서로 반영한다. 실패 시 코드와 세 데이터 파일을 함께 복구한다. 실행 옵션은 CLI 도움말과 dry-run 출력에 따른다.

내장 데이터는 계정을 새로 지정하지 않고 기준만 준비한다. 기본자격19·공통5·활성 팀별 특화10 구성을 유지한다. 전체 초기화는 대상 팀 설정도 미사용으로 바꾸며 계정은 보존한다. 로드 후 조직 관리에서 대상 팀을 설정하여 Auditor를 시험한다.
