# EKS 화면 안내

2026-10-22 · 업무 스키마 10 · 조직 스키마 2 · 단일 밝은 디자인

실행은 [루트 README](../README.md), 스타일은 [DESIGN.md](../docs/DESIGN.md), 일괄 기준 작성은 [Excel v5 안내](../docs/CATALOG_WORKBOOK.md)를 확인하세요.

## 계정과 메뉴

김민서·정하린·박준호·오지훈은 학습자입니다. 이서연은 팀 조직 관리자이며 시스템 운영자는 조직·사용자 관리와 선택한 Lv1의 인증 업무를 수행합니다. FT 역할·평가 메뉴·주관식·담당자 지정은 폐지했습니다. 오래된 평가 URL은 종료 안내와 홈 이동을 제공합니다.

학습자는 관리자가 요청한 실제 소속 조직의 필수 자격을 `내 계획`에서 선택하고 일정 → 목표 → 최종 확인을 거쳐 계획을 완료합니다. 상위 조직의 필수 목록을 상속하지 않습니다. 신규 계획 일정은 KST 오늘+7일 시작, 시작+21일 완료·+28일 평가로 한 번 채우며 사용자 수정값은 유지합니다. 목표 인증일과 목표는 직접 입력합니다. 미확정 본인 계획은 삭제 후 다시 작성할 수 있습니다.

홈의 `이어서 진행`은 `자격 상세`로 연결합니다. 상단에서 자격 설명·취득 조건·전체 진행·목표 인증일을 확인하고, 아래에서 인증Set을 선택해 내 학습 목표·일정·학습 범위·자료·평가 현황을 확인합니다. 자료는 여러 개를 동시에 펼칠 수 있으며 첫 직접 작성 자료만 기본으로 펼칩니다. `모두 펼치기/접기`와 인증Set별 펼침 기억을 제공하고, EDM Link·Confluence·일반 URL은 새 창에서 엽니다. `평가하기`를 선택한 뒤 지식 평가를 먼저 통과한 뒤 상황 대응 평가에 응시합니다. 별도의 학습 완료 기록·열람 확인은 요구하지 않으며, 기존 기록은 과거 근거로 보존합니다.

- 지식 평가: 개념·기준의 이해를 확인합니다.
- 상황 대응 평가: 상황 설명과 질문을 읽고 대응을 선택합니다. 실제 작업 관찰 평가가 아닙니다.
- 세로 번호에서 한 문항씩 응답하고 `답안 확인 → 제출`합니다. 미응답은 표시되고 답안은 500ms 후 저장됩니다.
- 유형별 통과는 독립적으로 유지합니다. 미통과 유형만 다시 응시하며 평가 승인·채점 대기는 없습니다.
- 수료증·인증서에서 자동 채점 점수·회차·확정 시각과 당시 기준을 확인합니다. 보유 자격은 취득 사실과 현재 유효 여부를 구분합니다.

## 인증Set·기준 편집

필수 평가는 두 유형이며 각 합격 기준은 직접 설정합니다. 지식 문항의 필기/Case 분류는 없습니다. 상황 대응 문항은 상황·질문·선택지·정답·배점을 입력합니다. 선택지의 정답 삭제만 미선택으로 바꾸고 앞선 선택지 삭제는 인덱스를 보정합니다.

학습 항목·평가 문항은 세로 번호 탐색입니다. 위/아래·Home/End 키, 선택·오류 표시, 44px 조작 크기를 유지하며 모바일에서도 가로 탭으로 바꾸지 않습니다. 유형 탭은 상단에 있으며 해제해도 작성 내용을 지우지 않습니다.

`자료 추가`에서 유형·자료명·본문/URL을 작성하고 목록에 추가합니다. 수정·삭제·순서 이동이 가능합니다. 편집 중 인증Set 저장을 누르면 자료의 필수값을 검사해 함께 반영합니다. 자료 URL에는 HTTP(S)만 허용합니다.

관리자의 계획 요청은 기본 작성 기한이 서버 요청일+28일이며 직접 수정할 수 있습니다. 요청별 대상 자격·계획 확정·유효 인증·현재 기준 제외 건수를 구분하고 인증Set은 평가 전·평가 중·일부 통과·수료로 표시합니다. 운영자는 관리 대상 Lv1을 명시적으로 선택합니다.

## 입력과 복구

- 저장 실패·다른 탭 충돌에서 입력을 유지하고 재시도/다시 불러오기를 안내합니다.
- 계정·조직·화면 이동 시 미저장 변경을 확인합니다. 다른 탭의 계정 선택은 현재 탭에 영향을 주지 않습니다.
- 기준 일괄 편집의 IndexedDB 보관은 서버 저장과 다릅니다. v1/v2 복구 초안은 현재 편집기에 자동 적용하지 않고 원본 다운로드를 제공합니다.
- 기존 FT/주관식/관찰식 필드를 보내는 오래된 화면은 서버에서 거부합니다. 새로고침해 현행 화면을 사용하세요.
- 시스템 운영의 일반 진행 초기화는 계획·배정·기준·조직 정책·사용자를 보존하고 과거 학습 기록·평가·수료·인증 등 대상 진행만 지웁니다. 이번 스키마 10 이관은 초기화하지 않고 진행을 보존합니다.

일반 화면·개별 편집 최대 1280px, 관리 목록·Excel 최대 1760px의 단일 밝은 스타일을 사용합니다. 인증은 검증용이며 PDF와 실제 종합평가 문항은 후속 범위입니다.


## 현재 조직 정책·학습 동선 (2026-10-21)

`/admin/policies`에서 같은 Lv1의 게시 자격 버전을 선정하고 실제 조직의 설명·담당 업무·필수 목록을 저장합니다. 사용자 소속은 깊이 제한 없이 지정합니다. 상속은 없고 관리자가 요청한 현재 필수 자격만 개인 계획을 시작할 수 있습니다.

홈의 이어서 진행은 `/qualifications/:assignmentId`의 `자격 상세`입니다. `?course=인증SetID`로 선택 인증Set을 지정하고, `?stage=assessment`에서 평가 유형을 선택합니다. 인증Set을 지정하지 않으면 작성 중 평가, 첫 미수료, 첫 인증Set 순으로 선택합니다. 학습 완료 기록은 작성하지 않습니다. 기존 직접 응시 URL과 자동 저장·재응시를 유지합니다. 각 페이지 하단은 현재 프로세스와 정적 검수 제약을 설명합니다. 재인증은 종합평가 완료 버튼으로 처리하며 실시간 AI 호출은 없습니다.

## 관리자 분리와 공지·레이아웃 (2026-10-21)

팀 조직 관리자와 선택 Lv1의 운영자는 `/admin/policies`에서 관리할 조직을 먼저 선택합니다. 조직에 직접 소속된 구성원을 여러 명의 세부 관리자로 지정할 수 있습니다. 세부 관리자는 상단 `인증 업무 관리`로 들어가면 조직별 자격 설정과 인증 대상자 관리만 사용하며, 자기 소속 조직 한 곳만 트리에 보입니다. 팀 후보 목록은 수정할 수 없습니다. 소속 이동 시 지정이 해제되고 기존 학습자 등 역할은 남습니다.

조직 선택은 왼쪽, 조직 속성·관리자·필수 자격은 오른쪽에 표시합니다. 트리에는 조직명만 표시하며 전체 경로는 상세에서 확인합니다. 1024px 미만에서는 선택한 조직명을 표시하는 접이식 탐색을 사용합니다. 관리자 후보는 이름으로 검색하고 체크합니다. 검색으로 숨겨진 사람도 `선택한 관리자` 영역에 남으며, 선택 해제와 체크 상태가 함께 바뀝니다. `저장 전 변경`은 아직 적용되지 않은 선택이며 `관리자 지정 저장` 후 반영합니다. 팀 공통 후보 목록은 오른쪽 하단의 `팀 전체 공통 설정`에서 편집합니다.

`/admin/notices`는 팀 공지, `/system/notices`는 전 조직 시스템 공지입니다. 홈의 두 공지 영역은 최신 3개와 전체 보기를 제공하며 실제 사용자 소속을 기준으로 표시합니다. 시스템 공지의 미게시 초안은 운영자 관리 화면에서만 보입니다.

`/admin/catalog`에서도 공통 관리 사이드바와 관리 조직을 유지합니다. 좁은 화면의 현재 메뉴 버튼으로 사이드바를 엽니다. 페이지 하단의 `MVP 프로세스 검토`는 기본 접힘이며 버튼으로 현재 절차·다음 행동·정적 AI 검수 설명을 확인합니다. 문단과 날짜를 구분하며 공지·학습 목표의 줄바꿈을 유지합니다.

## 자격 상태·재인증 (2026-10-22)

- `/admin/targets`: 인원 단위 대상자 Hold/해제. 체크한 인원을 별도 표시하며 사유를 입력하고 명시적으로 저장합니다. 세부 관리자는 실제 소속 한 곳의 직접 구성원만 조회·처리합니다.
- `/admin/credentials`: 개인 자격 검색·Active/Hold/Revoke 필터와 상태·이력 관리. 팀 관리자/선택 Lv1 운영자만 개인 효력을 변경합니다.
- 자격 편집의 운영 상태는 게시 여부와 별개입니다. 영향 검토 후 Hold/Revoke로 신규 계획·재인증을 막으며 이미 확정한 배정은 유지합니다. Revoke 버전은 재개하지 않습니다.
- 기간제 기준의 재인증 시작 개월은 기본 3입니다. 일괄 관리에도 동일하게 표시하며 Excel v5로 왕복합니다.
- `/certifications/:assignmentId`: 최초 취득 근거 아래 현재 효력·만료·재인증 시작일·상태 이력·기간 이력을 제공합니다. 본인은 재인증 시작과 최종 확인의 종합평가 완료로 갱신합니다. 실제 점수 없이 MVP 완료 사실을 기록합니다.
- 개인 Hold/대상자 Hold와 만료를 구분합니다. 상태 충돌이나 저장 실패 시 입력을 유지하며 최신 상태 확인 후 재검토합니다. 만료/Revoke 뒤에는 과거 인증을 되살리지 않고 새 요청·계획·인증Set 평가로 취득합니다.

재인증 사전 알림은 시작일 기본7일 전에 유효기간별 한 번입니다. 응시는 제출→답안 검토→최종 제출로 진행하며, 미응답은 팝업으로 안내합니다. 마지막 문항의 다음 버튼은 안내만 표시합니다. 검토 목록은20개씩 보이며 결과는 통과/미통과 배경·아이콘과 다음 행동을 구분합니다.


## 설정·기준 초기화와 서버 이전 (2026-10-22)

시스템 운영자만 `시스템 운영 → 테스트 관리`에서 세 작업을 사용합니다. 기존 `학습·평가 내역 초기화`는 계획·배정을 남깁니다. `설정·기준만 남기기`는 모든 조직의 계획·배정·공지·이력까지 지우며 사용자·조직 정책·자격/인증Set/문항과 현재 Hold 등 설정은 남깁니다. 보존·삭제 내역을 확인하고 `전체 초기화`를 입력합니다.

`설정·기준 데이터 이전`에서 파일을 내보내거나 다른 서버의 파일을 선택합니다. `파일 검사`에서 현재/파일 건수를 비교하고 `전체 교체`를 입력해 적용합니다. 파일은 Excel이 아닌 전용 JSON(최대 25MB)이며 대상 서버의 기존 설정·기준과 진행을 전체 교체합니다. 영구 백업을 만든 뒤 적용하고 완료 화면에서 보존/삭제 건수와 백업을 확인합니다. 파일의 운영자 계정으로 다시 접속합니다.

초기화·불러오기 후 다른 탭도 접속 계정을 다시 선택해야 합니다. 오래된 자동 저장·복구 초안은 새 데이터에 반영하지 않습니다. 완료 응답을 잃었으면 같은 탭에서 새로고침하고 운영자를 선택해 실제 영수증을 확인합니다. 재접속 자체로 작업을 다시 실행하지 않습니다. 상세 이전·복구 방법은 [안내](../docs/MASTER_DATA.md)를 확인하세요.
