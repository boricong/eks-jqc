- `/system/qualification-templates`: 운영자 전용 공통 정보 목록·검색·생성·수정·이력. Lv1 선택이 필요 없습니다.

- `/admin/policies`: 적용된 자격만 필수 선택합니다. 세부 관리자는 실제 소속 한 곳만 설정합니다.
- 현재 목록의 공통 정보와 확정 계획·배정·인증의 당시 정보를 분리합니다. 다른 창에서 공통 정보가 바뀌면 팀 입력을 유지하고 최신 정보를 다시 확인합니다.

## 화면 구성

인증 업무 관리 메뉴는 현황 조회 / 인증 운영 / 자격 기준 설정 / 팀 소통의 네 그룹·10개 메뉴로 나눕니다. 메뉴와 화면 제목은 공통 정의를 사용하며 URL과 권한은 유지합니다. 조직 필수 자격 설정은 필수 선택을 먼저 보여주고 조직 정보·관리자 지정은 접었다 펼칩니다. 계획 요청·진행은 요청 현황과 자격별 취득 진행으로 나누고 각 구역에 별도 필터를 둡니다. 모바일 메뉴는 Escape로 닫으면 열기 버튼으로 초점을 돌려줍니다.

2026-10-24 `평가 기준 검증` 기능을 종료했습니다. 비교 기록 메뉴·화면·시스템 조회 탭은 제공하지 않으며 이전 `/admin/comparisons` 및 상세 링크는 관리 조직을 유지해 인증 현황으로 이동합니다. 기존 평가·수료 결과와 인증 조회는 계속 사용합니다. API 종료와 과거 자료 보존 범위는 [루트 README](../README.md#평가-기준-검증-기능-종료-2026-10-24)를 따릅니다.

밝은 작업면과 인디고 강조, Pretendard를 사용합니다. 제목24px·구역18px·일반 UI/표14px·읽기 본문15px이며 모바일 입력은16px입니다. 둥근 카드 대신 목록·표·구분선으로 영역을 구분하고, 표는40px 기본 밀도로 고정하며 별도 밀도 선택은 없습니다. 관리 목록의 정렬·페이지 조작은 표 아래에 있습니다. 자격 목록의 `더보기`에서 삭제 영향 확인을 열 수 있습니다. 기존 메뉴·업무 흐름은 유지합니다.

계획 요청 현황은 개인별 한 줄로 이름·소속·요청 가능 상태·최근 요청과 기한을 표시하고, `상세`에서 요청 이력과 계획을 확인합니다. 요청 모달은 이름·조직 검색과 선택 수를 제공하며 검색으로 숨겨진 선택도 유지합니다. 기존 여유 밀도 설정은 무시하고 페이지 크기·정렬은 보존합니다.

개인 계획 최종 확인의 `요청 기준`은 마지막 보조 구역에 기본 접힘으로 표시합니다. 같은 계획에서는 수동 펼침을 유지하며 저장 오류와 조직 기준 변경 안내는 접힘 밖에 표시합니다.

디자인의 업무용 적용 규칙과 대비 보정은 [UX 설계안](../docs/EKS_프런트엔드_UX_설계안.md)을 따릅니다. CSS 진입점은 `design-tokens.css` → `base.css` → `style.css` → 기능별 CSS입니다. 공통 페이지 제목·저장 행동·속성 목록·행 작업 컴포넌트를 우선 사용합니다.

## 계정과 메뉴

김민서·정하린·박준호·오지훈은 학습자입니다. 이서연은 팀 조직 관리자이며 시스템 운영자는 조직·사용자 관리와 선택한 Lv1의 인증 업무를 수행합니다. FT 역할·평가 메뉴·주관식·담당자 지정은 폐지했습니다. 오래된 평가 URL은 종료 안내와 홈 이동을 제공합니다.

학습자는 관리자의 요청을 받아 `내 계획`의 `취득할 자격`에서 팀 자격을 고르고 `계획 시작`을 누릅니다. 시작 시 이번 요청에 자동 포함되며 별도 체크 목록·선택 저장은 없습니다. 요청 당시 필수에는 `[필수]`를 표시합니다. 일정 → 최종 확인으로 자격별 계획을 확정하며 `학습 목표(선택)` 단계는 필요할 때만 방문합니다. 이후 요청 전체의 `계획 수립 완료`를 확인합니다. 조직 필수 자격은 선택 사항이며 요청 당시 필수 목록만 이번 요청에 적용합니다. 필수 0개·팀 적용 0개에도 요청은 발송되며 후자는 자격 준비 대기입니다. 상위 조직의 필수 목록을 상속하지 않습니다. 신규 계획 일정은 KST 오늘+7일 시작, 시작+21일 완료·+28일 평가로 한 번 채우며 사용자 수정값은 유지합니다. 목표 인증일은 필수이며 학습 목표는 비워 두어도 됩니다. 입력한 목표는 최대2,000자이며 단계를 건너뛰어도 보존합니다. 미확정 본인 계획은 삭제 후 다시 작성할 수 있습니다.

`내 계획`은 제목과 계획 수립 요청부터 표시합니다. 별도의 `내 소속 필수 자격` 영역 없이 드롭다운에서 `[필수] 자격명 · v1`로 요청 당시 필수를 구분합니다. 요청 이후 조직 필수 설정이 바뀌어도 해당 요청의 표시는 유지하며, 취득·확정한 자격은 요청 현황에서 확인합니다.

홈 본문 첫 영역은 진행 중 자격을 한 번에 하나씩 보여주는 캐러셀입니다. 본인의 현재 소속·Lv1에 미완료 계획 수립 요청이 있으면 `자격 계획 수립` 카드 하나가 첫 항목에 표시됩니다. 미완료 요청 수·가장 빠른 작성 기한·현재 단계·안내문을 확인하고 `계획 수립하기`로 해당 요청을 엽니다. 기한이 같으면 기존 요청 순서를 따릅니다. 준비 대기·확인 필요 상태에서는 `요청 상태 확인`으로 표시합니다. 알림 읽음·초안 작성 중에는 유지하되, 필수·선택 계획이 모두 확정되거나 추가 계획 대상이 없어 서버가 완료 확인 가능으로 판단하면 숨깁니다. 요청 전체 완료는 자동 처리하지 않으며 `다음 할 일`의 `요청 전체 완료 확인`과 내 계획에서 별도로 수행합니다. Hold·비활성 소속에는 표시하지 않으며 진행 자격 통계에는 요청 수를 더하지 않습니다. 홈 재진입/계정 변경은 첫 항목, 데이터 갱신은 현재 선택을 유지합니다.

자격 카드에서는 자격명·배정 당시 버전·두 줄 설명·목표 인증일·인증Set 수료·평가 통과 현황을 확인하고 이전/다음, 좌우 방향키, 모바일 스와이프로 탐색합니다. 자동 재생·순환은 없으며 1건이면 탐색 조작을 숨깁니다. 홈의 `상세정보 보기`와 계획 완료 후 이동은 학습 화면으로 연결합니다.

학습자의 메뉴는 `내 계획 → 학습 → 평가 → 보유 자격`입니다. 학습의 자격 히어로는 블루그레이·데스크톱 최소160px/여백24px이며 왼쪽 제목24px·버전/상태·자격 정보, 오른쪽 수료/통과20px·목표일16px의 세 열과 인증 계획 보기를 제공합니다. 설명·영문명·기간·취득 조건은 기본 접힘이며 같은 배정의 펼침은 유지합니다. 학습 목록 링크는 없고 아래 인증Set 작업면과32px(모바일24px) 간격을 둡니다.

인증Set은 화이트·인디고 요약에 이름·버전·상태와 일정 수정/평가 이동을 모읍니다. 학습목표는 학습 화면에 표시하지 않으며 기존 계획/관리 조회와 입력값은 유지합니다. 학습 기간과 평가 예정일을 한 줄로 제공하고 평가일을 인디고로 강조합니다. 좁은 화면은 날짜 그룹별로 줄바꿈합니다.

학습 내용은 `학습범위 → 학습자료` 가로 탭입니다. 최초/새로고침은 학습범위이며 처음3개/전체 보기를 제공합니다. 펼친 긴 범위는 데스크톱 최대480px 내부 스크롤·키보드 스크롤, 모바일은 페이지 스크롤입니다. 자료 탭은 기존 유형별 세로 탭과 선택한 본문 하나를 제공합니다. 자료명은 본문/접근성 이름·툴팁, 중복 유형은 순번으로 구분하고 원문·줄바꿈·전체 URL·복사/자료 열기를 유지합니다. 유효한 HTTP(S)만 새 창에서 엽니다. 복사 실패 시 주소를 직접 선택할 수 있습니다.

비활성 패널은 렌더링하지 않습니다. 같은 계정의 인증Set별 마지막 가로 탭·범위 펼침·자료 선택/읽던 위치는 메모리에 보존하고 계정 변경/페이지 새로고침은 초기화합니다. 첫 자료는 첫 직접 작성 자료(없으면 첫 자료)입니다. 관리자 자료 조회의 기존 독립 펼침과 업무 저장 정책은 유지합니다.

평가에서는 자격명·인증Set·유형별 문항 수·합격 기준·상태와 이력·결과를 확인합니다. 학습 메뉴와 왕복해도 같은 자격·인증Set을 유지하며 목록 복귀 링크는 별도입니다. 자료 모달 대신 `학습으로 이동`을 사용합니다. 답안을 저장한 뒤 이동하고 실패·충돌 시 입력을 유지해 재시도하거나 명시적으로 이동을 선택합니다. 같은 회차의 저장 답안과 마지막 문항 위치를 복원하며 평가 선택 화면을 보는 것만으로는 회차를 생성하지 않습니다. 별도 학습 완료 기록·열람 확인은 요구하지 않습니다.

- 지식 평가: 개념·기준의 이해를 확인합니다.
- 상황 대응 평가: 상황 설명과 질문을 읽고 대응을 선택합니다. 실제 작업 관찰 평가가 아닙니다.
- 세로 번호에서 한 문항씩 응답하고 `제출 → 답안 확인 → 최종 제출`합니다. 미응답은 표시되고 답안은 500ms 후 저장됩니다.
- 유형별 통과는 독립적으로 유지합니다. 미통과 유형만 다시 응시하며 평가 승인·채점 대기는 없습니다.
- 수료증·인증서에서 자동 채점 점수·회차·확정 시각과 당시 기준을 확인합니다. 보유 자격은 취득 사실과 현재 유효 여부를 구분합니다.

## 인증Set·기준 편집

자격·인증Set은 별도 사용 등록 없이 바로 편집·저장합니다. 참조된 내용은 자동으로 새 버전을 만들며 팀 적용 버전과 기존 근거는 유지합니다. 미완성도 저장하지만 신규 계획·재인증 전에는 기준을 완성해야 합니다. 자격 삭제는 선택 버전만 처리하며 영향 확인과 사유를 요구합니다. 팀 적용 중인 버전은 삭제할 수 없고 기록이 있으면 목록에서 제외하여 보존합니다. 삭제한 항목은 조회만 가능합니다.

필수 평가는 두 유형이며 각 합격 기준은 직접 설정합니다. 지식 문항의 필기/Case 분류는 없습니다. 상황 대응 문항은 상황·질문·선택지·정답·배점을 입력합니다. 선택지의 정답 삭제만 미선택으로 바꾸고 앞선 선택지 삭제는 인덱스를 보정합니다.

학습 항목·평가 문항은 세로 번호 탐색입니다. 위/아래·Home/End 키, 선택·오류 표시, 44px 조작 크기를 유지하며 모바일에서도 가로 탭으로 바꾸지 않습니다. 상위에는 이름이 있는 세로 편집 탐색(기본정보/학습자료/학습 항목/지식/상황 대응), 내부에는 번호만 있는 문항 탐색을 둡니다. 유형을 해제해도 내용을 지우지 않습니다.

`자료 추가`에서 유형·자료명·본문/URL을 작성하고 목록에 추가합니다. 수정·삭제·순서 이동이 가능합니다. 편집 중 인증Set 저장을 누르면 자료를 함께 반영하며 미완성 항목은 신규 운영 전 보완합니다. 자료 URL에는 HTTP(S)만 허용합니다.

관리자의 계획 요청은 기본 작성 기한이 서버 요청일+28일이며 직접 수정할 수 있습니다. 요청별 대상 자격·계획 확정·유효 인증·현재 기준 제외 건수를 구분하고 인증Set은 평가 전·평가 중·일부 통과·수료로 표시합니다. 운영자는 관리 대상 Lv1을 명시적으로 선택합니다.

## 입력과 복구

- 저장 실패·다른 탭 충돌에서 입력을 유지하고 재시도/다시 불러오기를 안내합니다.
- 계정·조직·화면 이동 시 미저장 변경을 확인합니다. 다른 탭의 계정 선택은 현재 탭에 영향을 주지 않습니다.
- 기준 일괄 편집의 IndexedDB 보관은 서버 저장과 다릅니다. v1/v2 복구 초안은 현재 편집기에 자동 적용하지 않고 원본 다운로드를 제공합니다.
- 기존 FT/주관식/관찰식 필드를 보내는 오래된 화면은 서버에서 거부합니다. 새로고침해 현행 화면을 사용하세요.
- 시스템 운영의 일반 진행 초기화는 계획·배정·기준·조직 정책·사용자를 보존하고 과거 학습 기록·평가·수료·인증 등 대상 진행만 지웁니다. 이번 스키마 12 이관은 초기화하지 않고 진행을 보존합니다.

일반 화면·개별 편집 최대 1280px, 관리 목록·Excel 최대 1760px의 단일 밝은 스타일을 사용합니다. 인증은 검증용이며 PDF와 실제 종합평가 문항은 후속 범위입니다.


## 현재 조직 정책·학습 동선 (2026-10-21)

`/admin/qualifications`에서 기본자격을 팀에 등록·설정하고 적용 버전을 확정합니다. `/admin/policies`에서는 적용된 팀 자격 중 실제 조직의 필수 목록과 설명·담당 업무를 저장합니다. 사용자 소속은 깊이 제한 없이 지정합니다. 상속은 없습니다. 필수 설정 여부와 무관하게 요청받은 학습자는 현재 팀 적용 자격으로 개인 계획을 시작할 수 있습니다. 요청 당시 필수와 포함한 계획 전체는 요청 완료 시 검사합니다.

학습 목록은 `/qualifications`, 평가 목록은 `/qualifications?stage=assessment`, 보유 자격은 `/qualifications?filter=certified`입니다. 상세는 `/qualifications/:assignmentId`이며 `?course=인증SetID`로 선택 인증Set을 지정합니다. `stage=assessment`에서만 평가를 표시합니다. 인증Set을 지정하지 않으면 작성 중 평가, 첫 미수료, 첫 인증Set 순으로 선택합니다. 기존 직접 응시 URL·자동 저장·재응시·수료증 돌아가기를 유지하며 학습 열람을 업무 데이터로 저장하지 않습니다. 각 페이지 하단은 현재 프로세스와 정적 검수 제약을 설명합니다. 재인증은 종합평가 완료 버튼으로 처리하며 실시간 AI 호출은 없습니다.

## 관리자 분리와 공지·레이아웃 (2026-10-21)

팀 조직 관리자와 선택 Lv1의 운영자는 `/admin/policies`에서 관리할 조직을 먼저 선택합니다. 조직에 직접 소속된 구성원을 여러 명의 세부 관리자로 지정할 수 있습니다. 세부 관리자는 상단 `인증 업무 관리`로 들어가면 인증 현황·취득 대상자 상태·조직 필수 자격 설정만 사용하며, 자기 소속 조직 한 곳만 트리에 보입니다. 팀 후보 목록은 수정할 수 없습니다. 소속 이동 시 지정이 해제되고 기존 학습자 등 역할은 남습니다.

조직 선택은 왼쪽, 조직 속성·관리자·필수 자격은 오른쪽에 표시합니다. 트리에는 조직명만 표시하며 전체 경로는 상세에서 확인합니다. 1024px 미만에서는 선택한 조직명을 표시하는 접이식 탐색을 사용합니다. 관리자 후보는 이름으로 검색하고 체크합니다. 검색으로 숨겨진 사람도 `선택한 관리자` 영역에 남으며, 선택 해제와 체크 상태가 함께 바뀝니다. `저장 전 변경`은 아직 적용되지 않은 선택이며 `관리자 지정 저장` 후 반영합니다. 팀 적용 버전은 `팀 자격 설정 → 팀 적용`에서 편집하며 조직 설정에는 해당 화면의 링크와 필수 선택을 제공합니다.

`/admin/notices`는 팀 공지, `/system/notices`는 전 조직 시스템 공지입니다. 홈의 두 공지 영역은 최신 3개와 전체 보기를 제공하며 실제 사용자 소속을 기준으로 표시합니다. 시스템 공지의 미게시 초안은 운영자 관리 화면에서만 보입니다.

`/admin/catalog`에서도 공통 관리 사이드바와 관리 조직을 유지합니다. 좁은 화면의 현재 메뉴 버튼으로 사이드바를 엽니다. 페이지 하단의 `MVP 프로세스 검토`는 기본 접힘이며 버튼으로 현재 절차·다음 행동·정적 AI 검수 설명을 확인합니다. 문단과 날짜를 구분하며 공지·학습 목표의 줄바꿈을 유지합니다.

## 자격 상태·재인증 (2026-10-22)

- `/admin/targets`: 인원 단위 대상자 Hold/해제. 체크한 인원을 별도 표시하며 사유를 입력하고 명시적으로 저장합니다. 세부 관리자는 실제 소속 한 곳의 직접 구성원만 조회·처리합니다.
- `/admin/credentials`: 개인 자격 검색·Active/Hold/Revoke 필터와 상태·이력 관리. 팀 관리자/선택 Lv1 운영자만 개인 효력을 변경합니다.
- 자격 편집의 운영 상태는 내용의 완성도와 별개입니다. 영향 검토 후 Hold/Revoke로 신규 계획·재인증을 막으며 이미 확정한 배정은 유지합니다. Revoke 버전은 재개하지 않습니다.
- 기간제 기준의 재인증 시작 개월은 기본 3입니다. 일괄 관리에도 동일하게 표시하며 Excel v7로 왕복합니다.
- `/certifications/:assignmentId`: 최초 취득 근거 아래 현재 효력·만료·재인증 시작일·상태 이력·기간 이력을 제공합니다. 본인은 재인증 시작과 최종 확인의 종합평가 완료로 갱신합니다. 실제 점수 없이 MVP 완료 사실을 기록합니다.
- 개인 Hold/대상자 Hold와 만료를 구분합니다. 상태 충돌이나 저장 실패 시 입력을 유지하며 최신 상태 확인 후 재검토합니다. 만료/Revoke 뒤에는 과거 인증을 되살리지 않고 새 요청·계획·인증Set 평가로 취득합니다.

재인증 사전 알림은 시작일 기본7일 전에 유효기간별 한 번입니다. 응시는 제출→답안 검토→최종 제출로 진행하며, 미응답은 팝업으로 안내합니다. 마지막 문항의 다음 버튼은 안내만 표시합니다. 검토 목록은20개씩 보이며 결과는 통과/미통과 배경·아이콘과 다음 행동을 구분합니다.


## 설정·기준 초기화와 서버 이전 (2026-10-22)

시스템 운영자만 `시스템 운영 → 테스트 관리`에서 세 작업을 사용합니다. 기존 `학습·평가 내역 초기화`는 계획·배정을 남깁니다. `설정·기준만 남기기`는 모든 조직의 계획·배정·공지·이력까지 지우며 사용자·조직 정책·자격/인증Set/문항과 현재 Hold 등 설정은 남깁니다. 보존·삭제 내역을 확인하고 `전체 초기화`를 입력합니다.

`설정·기준 데이터 이전`에서 파일을 내보내거나 다른 서버의 파일을 선택합니다. `파일 검사`에서 현재/파일 건수를 비교하고 `전체 교체`를 입력해 적용합니다. 파일은 Excel이 아닌 전용 JSON(최대 25MB)이며 대상 서버의 기존 설정·기준과 진행을 전체 교체합니다. 영구 백업을 만든 뒤 적용하고 완료 화면에서 보존/삭제 건수와 백업을 확인합니다. 파일의 운영자 계정으로 다시 접속합니다.

초기화·불러오기 후 다른 탭도 접속 계정을 다시 선택해야 합니다. 오래된 자동 저장·복구 초안은 새 데이터에 반영하지 않습니다. 완료 응답을 잃었으면 같은 탭에서 새로고침하고 운영자를 선택해 실제 영수증을 확인합니다. 재접속 자체로 작업을 다시 실행하지 않습니다. 상세 이전·복구 방법은 [안내](../docs/MASTER_DATA.md)를 확인하세요.

비필수 초안을 삭제하면 이를 사용하는 미완료 요청에서도 자동 제외됩니다. 필수는 대상으로 남습니다. 이전에 선택만 저장한 항목은 `계획 미작성`으로 표시하며 비필수 항목에만 `요청에서 제외`를 제공합니다.
